## 二、本轮发现并修复的真 bug

### [P2] 登录用户每页对 profiles 发 406 报错
**现象**：实测登录态打开任意页面,DevTools 都报一条 `406 /rest/v1/profiles`。
**根因**：[lib/auth/useUser.ts](../lib/auth/useUser.ts) 用 `.single()` 查 profile —— PostgREST 在 0 行时返 406(报错),而非 null。当用户的 profile 行缺失(注册时 insert 失败/未建)时,**每打开一页都刷红错**,评委开 DevTools 满屏报错,观感差。
**修复**：
- `.single()` → `.maybeSingle()`(0 行返回 null,不报错,优雅降级)
- 注册页 profile `insert` → `upsert`(幂等,杜绝漏建导致的永久 406)
**验证**：补 profile 行后实测 406 消除、console 干净。
