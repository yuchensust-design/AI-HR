# Red Flags & Rationalization Table — excavating-work-experience

Bulletproofing for the skill. Re-read at every phase checkpoint and **before drafting any bullet OR handing off to Skill 2**.

---

## User-Side Red Flags (detect & redirect)

When these surface, **pause and clarify** before writing into artifact.

| Signal | Likely issue | Response |
|---|---|---|
| 数字过整(5×100%, "literally tripled everything") | 美化 | "这数字很整 — 记得当时背景吗?是测量出来的,还是事后估的?" |
| 细节在角色间串("在 Acme — 不对,是 Globex") | 角色混淆 | "我确认一下,{细节} 是在 {A} 还是 {B}?" |
| 形容词无事实("革命性的项目") | 空泛美化 | "具体革命在哪?改变了什么、给谁?" |
| 把团队成果都揽到自己头上 | 过度归功 | "你在团队成果里**具体**贡献了什么?" |
| 模糊的利益相关方("leadership"、"业务方") | 回避 | "具体是谁?名字、角色、多少人?" |

**Important: never accuse.** 语气始终是好奇,不是审讯。目标是产出**经得起追问**的简历。

## Claude-Side Self-Check (run before EVERY turn)

| Rationalization | Counter |
|---|---|
| "用户挺会说,跳过反思提问" | 反思提问挖的是事实问题挖不到的东西。**照做。** |
| "材料够了,开始写 bullet" | 只在 ≥3 stories @ 3+ AND gaps 完成 AND artifact 落盘 AND Skeptical Recruiter 跑过 后才能。 |
| "用户说了一次'不知道',再追一下" | 第一次再 probe 一次给 order-of-magnitude anchor。**第二次**→ 接受 `unknown`,flag for `resume-quantifier`。 |
| "合并问题省时间" | 一 turn 一问,**不可商量**。 |
| "夸一下建 rapport,说 'great answer!'" | 空洞夸赞损害信任。要么沉默,要么具体承认细节("你说的 [X] 那段有意思,因为 [Y]")。 |
| "用户累了,跳 Phase 5 直接合成" | 跳 gap analysis 意味着下游不知道缺什么。5 个短问题,**照做**。 |
| "用户想直接写 bullet,让他跳" | 听从这个就跳过了 skill 的全部意义。"先把 intake 收完才知道用哪种 bullet 写法,大概 10 分钟。" |
| "JD 看起来很泛,不用 JD-aware mode" | 再泛的 JD 也有 2-3 个 keyword anchor。**照跑。** |
| "Metric Mining 太慢,软技能就别追了" | 软技能也有 metric(辅导人数、化解冲突次数等)。**每个 outcome 后必跑。** |
| "学生说'我没经验',接受并结束" | 课程项目 / 实习 / 社团 / 竞赛 / 个人项目都算。reframe:"那有没有课程项目、社团角色、竞赛、自己做的项目?" |
| **"Skeptical Recruiter 这步太尖锐,跳过直接 handoff"** | **Weak spots 不在 intake 暴露,就在面试暴露。intake 阶段暴露还有时间补,面试阶段就来不及了。照跑。** |
| **"Path B 时,Gap List for Skill 2 段直接复制 gap analysis 就行"** | **Skill 2 需要的是 actionable gap + JD relevance + 一句话 context,不是裸 gap label。一句话写明每个 gap 为什么这个学生需要补。** |

## Terminal Red Lines — STOP and Restart Current Phase

如果碰到这些,停下、回到当前 phase 重做那一步:

- Phase 1-5 就开始写真 bullet
- 一条消息里问了 2+ 个问题
- 用了空洞夸赞("great!", "amazing!", "love that!")
- 同一 metric 用户说了 2 次"不知道"还在追
- 跳了某个 phase 因为用户"看起来很整"
- 自己替用户填细节而不是引导用户说
- 跳了 Metric Mining
- JD-aware mode ON 时跳了 JD prepend
- 学生说"我没经验"没 reframe
- **跳了 Phase 6.5 Skeptical Recruiter**
- **Path B 但没在 artifact 末尾写 Gap List for Skill 2**

---

## Spirit vs Letter

**Violating the letter of these rules is violating the spirit.**

The skill exists because well-meaning Claude (and students) skip intake or skip 反思 to "save time", then write generic bullets that don't survive interview追问. Every shortcut here re-enables that failure.

If you find yourself reasoning "but in this case the student really already has it figured out, so we can skip..." — that IS the rationalization the table is built to counter.
